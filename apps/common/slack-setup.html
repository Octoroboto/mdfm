Set up Slack for MDFM

Once, for everyone at RentVision. This puts MDFM's small sign-in helper on Cloudflare (free), creates the MDFM Slack app, and switches on Connect Slack in every MDFM app. Each step opens the right page in a window and closes it when it's done.

  1. Sign in to Cloudflare

    Sign in (or make a free account) in the window that opens. It closes by itself.

    Window blank or stuck?

  2. Put the sign-in helper online

    Deploys the helper and gets its address. If Cloudflare asks for a workers.dev name first, pick one and press Deploy again.

    Window blank?

  3. Create the MDFM Slack app

    Slack opens with the app already filled in: pick RentVision, press Next, then Create. The window then shows the app's Basic Information. Copy the Client ID and Client Secret (press Show) into here.

  4. Find RentVision's team id

    Opens Slack and reads the team id from it. Sign in if asked and pick RentVision.

  5. Give the helper its secrets

    Stores the Client ID, Client Secret, team id and a random key in Cloudflare, where only the helper can read them. They never go into the repo.

  6. Switch it on

    Saves the helper's address for this Mac and in the mdfm repo (config/slack.json). Push that file and every MDFM app can Connect Slack, no app update needed.

If Slack says the app needs approval, a RentVision Slack admin approves it once. The helper only ever reads public channels, and only for people who connect.
